WARP HUB - releases
===================

Reporting bugs: the release number is in the screen title ("WARP HUB 0.15")
and in the Shell: Version SYS:WarpApps/WarpHub. Describe what
happened and give the release number:
https://github.com/cizar-szymon/Amiga_WarpHub/issues


0.15 (25.11.2026, beta release)
-------------------------------
- A button next to the padlock in the title bar (or the key F1) opens the
  window "Downloaded files": on top how many files of how many are downloaded
  (and how many MB), below every file of the install with its state:
  waiting / checking / percentage / done / error. The window is updated while
  downloading and shows the current file. The button is green while a
  download runs.
- A resumed install shows its progress also while it checks the files
  downloaded before (big game files: some minutes).

0.14 (25.11.2026, beta release)
-------------------------------
- A stopped install (network, Stop) keeps the files that came whole; the
  next Install / Update downloads only the rest. A big game on a line that
  breaks off installs in a few tries.
- A file the network stopped answering on is tried up to 3 times.
- Time limit for data: 30 s.

0.13 (25.11.2026, beta release)
-------------------------------
- The time for the certificate check: time servers first (NTP, UDP 123),
  and when none answers (e.g. a router blocks port 123) the time of a web
  server's answer (HTTP, port 80). An Amiga with a wrong clock then connects
  without setting the date. The clock of the Amiga is not changed.
- WarpHubCLI TIME shows the clock of the Amiga, the NTP time and the time of
  the web servers.
- A connection that stalls (the server or the network stops answering) ends
  after 30 s with a message naming the server; a download is tried once
  more, and Refresh only leaves out the missing pictures and texts. Stop
  ends the wait at once.

0.12 (25.11.2026, beta release)
-------------------------------
- When the encrypted connection (TLS) fails, the message gives the reason
  and the data for a bug report, e.g. "TLS handshake with
  raw.githubusercontent.com failed: connection closed during the handshake
  [SSL 5, errno 0, OpenSSL 3.5.4]": the server, the reason (AmiSSL error,
  connection closed, no answer), the TLS error code, the network error code
  and the AmiSSL version. Please send the whole message with a bug report.
- WarpHubCLI takes an address with a port (CATALOG=https://server:port/file).

0.11 (25.11.2026, beta release)
-------------------------------
- Faster start: WARP HUB remembers the versions of the installed games and
  reads a game program again only when the file has changed. The catalog of
  the games (public and private) is downloaded only when it has changed; the
  pictures and texts in WarpHub-cache are checked by size and date, and the
  pictures of the window are loaded again only for new games or games with a
  new picture.
- Option TIMES (Tool Type of the icon or in the Shell: WarpHub TIMES) writes
  the times of the start and of every refresh to RAM:WarpHub-times.txt.

0.10 (24.11.2026, beta release)
-------------------------------
- Refresh (when the user presses it) also checks the chosen, installed game:
  whether it has old versions (drawer old) and bug reports (drawers bugNNN in the
  drawer user). When it has, a window of its own opens with the list, the sizes
  and the buttons Delete old versions / Delete bug reports (each asks for
  confirmation). Saved games and settings are not touched.
- The windows with questions open in the middle of the WARP HUB window.

0.9 (24.11.2026, beta release)
------------------------------
- Every longer process says on the bar what it is doing: Checking the files
  of a game (e.g. "Checking files: 12 of 33, DESERT.MIX (41%)") and Refresh
  ("Loading pictures and texts: 5 of 13") show the file and the progress, like
  downloading. The Stop button also stops the check of the files; stopping
  gives the message "Stopped." without a window.

0.8 (24.11.2026, beta release)
------------------------------
- The Install button becomes Uninstall for an installed game, also an
  old version; WARP HUB asks before it deletes. It deletes only the files
  that WARP HUB installed (program, icons, texts, data); saved games,
  settings and bug reports in the drawer user stay. WARP HUB does not
  uninstall itself.

0.7 (24.11.2026, beta release)
------------------------------
- Padlock in the title bar: log in to your own private source of full
  packages (server address and password; the certificate of the server is
  confirmed once and remembered). "Remember" logs in at the start.
- Refresh looks at the game drawers again: a game added, deleted or moved
  while WARP HUB is open is shown right away.

0.5 (19.11.2026, beta release)
------------------------------
- Run button (next to the language) and the Return key: starts the chosen
  installed game like its icon.

0.4 (19.11.2026, beta release)
------------------------------
- WARP HUB lives in SYS:WarpApps as a program with its icon, like the other
  Warp programs (no drawer of its own); updating itself replaces the program,
  the previous version stays as WarpHub.old.
- The cache is the drawer WarpHub-cache next to the program.

0.3 (19.11.2026, beta release)
------------------------------
- First release: a gallery of the games and programs for Warp cards with
  pictures, descriptions, requirements and the history of releases; English,
  Polish, German.
- Installs and updates straight from GitHub (AmiSSL / WarpSSL), only the
  changed files, each one checked with SHA-256; the old program goes to old/.
- The player's files stay: game data, settings, saved games, the icon with
  its Tool Types.
- How to start: what to add and where.
- At every start it recognises the installed games in the games and
  programs drawers.
- WARP HUB updates itself (group Programs).
